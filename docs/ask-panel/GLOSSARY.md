# Ask panel — glossary

Product terms only. How each is built belongs in the other documents.

**Ask panel** — The small floating window opened by the ask shortcut, where the person types a question to one bot and
reads the streamed reply. Distinct from upstream's *Talk panel* (push-to-talk, voice) and from upstream's *companion*
(the paired phone/device feature), which share no meaning with it.

**Ask shortcut** — The global key combination that opens the Ask panel from any app.

**Bot** — An existing MausBot agent with its own conversations, settings, permissions and model.

**Selected bot** — The bot an ask goes to. Remembered between launches.

**Quick asks** — The selected bot's dedicated conversation that receives Ask panel questions, visible in full MausBot.

**Previous window** — The window the person was using immediately before pressing the ask shortcut.

**Window picker** — The list of open windows from which the person chooses one to capture, when the previous window is
unknown or not wanted.

**Include window** — The person's explicit choice to attach a capture of a window to the next ask. Off unless turned on.

**Capture preview** — The visible copy of a capture shown before sending; removing it means it is never sent.

**Screen-aware question** — An ask that carries a capture of a window together with typed text.

**On-demand capture** — A capture made only because the person asked for it in that moment; never periodic.

**Needs you** — A bot's state when it is waiting for the person (an approval or a question), which the Ask panel only
reports and the full app resolves.

**Background available** — MausBot is running in the logged-in session and the Ask panel can open without launching
anything; nothing runs while the Mac sleeps.

**Subscription-only** — Using the person's own signed-in AI account through the provider's own software, with no
separately billed key.

**Self-improvement** — Adjusting future behaviour from remembered preferences and corrections; never changing code.

**Incremental resource cost** — Extra idle CPU, memory, energy or wakeups compared with stock MausBot on the same Mac.

**Local demo** — The tested build shown on one real Mac, without signed public distribution.
